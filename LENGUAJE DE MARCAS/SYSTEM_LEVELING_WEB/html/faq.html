PREGUNTAS FRECUENTES

¿COMO DESCARGO SYSTEM LEVELING APP?

Para descargar SYSTEM LEVELING APP debes de ser invitado por el propio desarrollador debido a que esta es una aplicacion cerrada es decir
que no es de libre descarga ni tampoco es de pago si no que es completamente privada y sin que el desarrrolador la comparta no podrias descargarla.

¿CUANDO SALE SYSTEM LEVELING APP?

SYSTEM LEVELING APP no cuenta actualmente con una fecha exacta en la que este lista su version 1.0 es decir su primera version funcional
debido a esto no se podria decir una fecha exacta.

¿EN QUE DISPOSITIVOS ESTARA DISPONIBLE SYSTEM LEVELING APP?

SYSTEM LEVELING APP estara disponible para dispotivos android, windows y linux. De momento se sabe que no estara disponible para
dispotivos IOs pero en un futuro se intentara integrarlos tambien

¿COMO SE SI SOY APTO PARA EL SISTEMA?

Para saber si eres apto para el sistema primero deberas poder tener acceso a la aplicacion una vez tengas acceso a la aplicacion podras
comprobar si eres apto, debido a que el sistema al poco tiempo que lo estes usando sera capaz de juzgar si debes de seguir con su ayuda
o si este decide el no ayudarte debido a que no le habras demostrado los valores necesarios para que te brinde su ayuda. Todo esto seria
en el modo inmersivo es decir el modo mas realista posible.

¿QUE ES EL MODO INMERSIVO?

El modo inmersivo de SYSTEM LEVELING APP es el modo donde el sistema es lo mas realista posible es decir el sistema te juzgara y este
sera capaz de decir si te ayuda o no ademas de que te encargara misiones mas adaptadas a tu dia a dia y tambien sera mucho mas agresivo.
Este modo una vez activado no se puede desactivar y en este modo las penalizaciones son mucho mas agresivas al igual que las misiones
pero una vez activado y una vez que el sistema detecte que eres apto tendras una incima probabilidad de recibir su bendicion.

¿QUE ES LA BENDICION DEL SISTEMA?

La bendicion del sistema es una cualidad unica del modo inmersivo esta lo que hace es que el sistema deje de ser "un sargento de hierro"
Y se volvera mas amistoso y este buscara beneficio para ti incluso en cosas en las que no le has pedido aun asi tendra aun
una pizca de sargento de hierro.
