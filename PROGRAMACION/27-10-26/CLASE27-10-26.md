2. CONDICIONAL

SI UNA CONDICION ES CIERTA, EJECUTA EL CODIGO ASIGNADO:

IF(CONDICION) {
// CODIGO A EJECUTAR
}
LA CONDICION PUEDEN SER:

. COMPARACIONES:
			A > B MAYOR QUE
			A < B MENOR QUE
			A <= B MENOR O IGUAL
			A >= B MAYOR O IGUAL
			A == B IGUAL
			A != B DISTINTO
			(A Y B PUEDEN SER CUALQUIER EXPRESION)
			EJEMPLO:
			
			int a = 3;
			if(a < 2) System.out.println("Menor a 2"); // No se ejecutaría
			if(a == 3) System.out.println("Vale 3"); // se ejecutaría
			IMPORTANTE:lAS CADENAS DE CARACTERES SE COMPARAN CON "equals" Y NO CON "==".
			
			EJEMPLO:

			String cadena = "Hola mundo";
			if(cadena.equals("Hola mundo")) {
				System.out.println("Gracias por saludar");
			}
			// No se pone: if(cadena == "Hola mundo") // No funciona

4. OPERADORES LOGICOS

SE USAN EN SITUACIONES EN LAS QUE SE NECESITAN QUE SE CUMPLAN VARIAS CONDICIONES A LA VEZ O SOLO UNA  DE VARIAS.



OPERADOR \&\& (y lógico \[AND]): SE USAN EN SITUACIONES EN LAS QUE SE NECESITAN QUE SE CUMPLAN VARIAS CONDICIONES A LA VEZ

EJEMPLO:

int a = 3;
int b = 4;
if (a < 7 \&\& b > 2) {
System.out.println("Se cumplen las condiciones");
}
if (a < 7 \&\& b > 2 \&\& (a+b) == 7 \&\& (a-b) == -1 \&\& b == 4) {
System.out.println("Se cumplen las condiciones");
}

OPERADOR || (o lógico \[OR]): SE USAN EN SITUACIONES EN LAS QUE SE NECESITAN QUE SE CUMPLA AL MENOS UNA CONDICIÓN

EJEMPLO:

int a = 3;
int b = 4;
if (a < 7 || b > 2) {
System.out.println("Se cumplen alguna condicion");
}
if (a < 7 || b > 2 || (a+b) == 7 || (a-b) == -1 || b == 4) {
System.out.println("Se cumplen alguna condicion");
}

SE PUEDEN MEZCLAR

EJEMPLO:

int a = 3;
int b = 4;
if (a < 7 || b > 2 \&\& (a+b) == 7 || (a-b) == -1 \&\& b == 4) {
System.out.println("Se cumplen alguna condicion");
}

IMPORTANTE: \&\& TIENE PRIORIDAD SOBRE ||.

OPERADOR NEGACION !: CONVIERTE LOS VERDADERO EN FALSO Y LO FALSO EN VERDADERO

SE INDICA CON UNA ADMINARION AL PRINCIPIO DE LA EXPRESION:

int a = 3;
if(! a == 2) {
//Se ejecua esta parte
}
EJEMPLO:

// Solo afecta hasta el siguiente \&\& o ||
}
if(a == 3 || ! b == 1 \&\& (a + b) > 0){

}
